# Searching & Sorting

Ten fundamental C++17 implementations for the second DSA section.

| # | Problem / algorithm | Complexity |
|---|---|---|
| 1 | Linear Search | O(n) |
| 2 | Binary Search | O(log n) |
| 3 | First and Last Occurrence | O(log n) |
| 4 | Lower Bound | O(log n) |
| 5 | Bubble Sort | O(n²) |
| 6 | Selection Sort | O(n²) |
| 7 | Insertion Sort | O(n²) |
| 8 | Merge Sort | O(n log n) |
| 9 | Quick Sort | O(n log n) average |
| 10 | Search in Rotated Sorted Array | O(log n) |

All programs read from standard input. Compile with:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic 02_binary_search.cpp -o solution
```
